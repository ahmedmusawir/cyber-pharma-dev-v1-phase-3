## Lessons Learned

- **Run preflight commands from one fixed directory.** The v1.1 preflight mixed pack-relative and repo-root paths, so QF-03 (`git diff -- src/`) would have passed vacuously from the pack folder. Pin the working directory and use a variable (`$QAM`) for the pack path.
- **Editor swap files are a credential-leak path.** `.env*.local` does not match `.env.qa.local.swp`; it showed up as untracked during the session. Stage explicit paths only; never `git add -A` near credential files.
- **An identity check needs a recorded reference.** "main-dev" existed only as a label. `supabase/.temp/linked-project.json` (tracked) points to a different project, so it can't serve as the reference. The authority is now the Director's existing `.env.local` approval plus the recorded fingerprint `8ca83fc75bdf9fbc`.
- **Read env files with the parser the app uses.** QF-15 now uses Node's `--env-file`, the same parser that feeds the standalone server, so quoted values agree.
- **The Next standalone output carries no `.env*` files.** Runtime config must be passed at start (`node --env-file=.env.local .next/standalone/server.js`).
