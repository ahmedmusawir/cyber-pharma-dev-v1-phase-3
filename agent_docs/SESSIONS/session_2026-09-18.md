## Lessons Learned

- A "build with no env" instruction is meaningless while `.env.local` exists — Next loads it regardless of the shell. Blank-override the keys for the one command instead; never move the env file.
- Recon reports go in `agent_docs/RECON/`, not `agent_docs/RESPONSES/` (Operator correction, this session).
- A review's pinned SHA can belong to a sibling repo. "Not an ancestor" and "object does not exist" are different answers — check `git cat-file -t` before concluding anything.
- Don't guess a finding-ID mapping when the source reviews aren't on disk. Key by verified claim, flag NEEDS DIRECTOR, and fill the IDs when the documents arrive.
- Check the version line of any dropped spec before quoting it — the Phase-2.1 copies are v1.0 while the code cites v1.3/v1.4.
