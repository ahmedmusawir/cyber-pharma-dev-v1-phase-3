## 1. Disclosure design (R-015, AC-101–106)

**Component.** New presentational `src/components/owedbook/SummaryUnattributedNote.tsx`. Props: `underpaid: number` (K) and `summary: OwedBookSummaryRow[]`. It computes `S = Σ commercial_dollars`, `gap = round2(underpaid − S)`, returns `null` when `gap < 0.01`, else one `<p data-testid="summary-unattributed-note">` whose text is a single template string: `${usd(gap)} in underpaid dollars belongs to claims awaiting a PBM match and isn't shown in this breakdown.` The copy lives in one constant in that file. Nothing else does arithmetic.

**Same-filters pair (AC-103).** Object identity on the context's `filters` reference. Two new state tags in `OwedBookScreen.tsx`: `kpiFilters` and `summaryFilters` (`OwedBookFilters | null`, both start `null`). The KPI effect (`:77-86`) sets `kpiFilters = filters` in the same `!cancelled` branch that sets `kpis`, and `null` in the catch branch (the `ZERO_KPIS` fallback stays). The summary branch of the rows effect (`:95-100`) sets `summaryFilters = filters` beside `setSummaryRows(s)`. Tag and value always move together under the same `cancelled` guard, so a tag always describes the value next to it. Render guard: `isSummary && !loading && !error && kpiFilters === filters && summaryFilters === filters`. A filters change makes `filters` a new reference, so both tags mismatch until each request resolves for it; a cancelled request never writes a tag; a rejected KPI writes `null`; K for A with S for B fails one side. `clearFilters` reuses the `EMPTY` reference, so two consecutive clears are a no-op pair, which is correct.

**Where K and S meet.** K already lives in `kpis.commercial_underpaid` (KPI effect, all tabs). S already lives in `summaryRows` (summary branch, Summary tab only). No new request. The footer is one added line after the table block (`:252`), before the outer `</div>` — a pure addition; the DataTable lines do not move. Tab switch away removes it (`isSummary`); switching back re-runs the summary effect (deps include `activeTab`), so it comes back **with a new request** after the skeleton (AC-104: stated).

**Helpers.** `usd` is importable from `src/components/owedbook/format.ts:11`. `round2` is **not** — see contradiction C-1. Proposed: add `export const round2 = (n: number) => +n.toFixed(2);` to `format.ts`, byte-identical to the service's expression at `owedbook.ts:56`. Needs a ruling.
